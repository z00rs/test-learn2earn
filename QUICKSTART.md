# 🚀 Quick Start Guide

## One-Command Deployment

```bash
# Clone and setup
git clone https://github.com/z00rs/test-learn2earn.git
cd test-learn2earn
./setup.sh
```

## What You Need

1. **VeChain Testnet Private Key** - For contract deployment
2. **WalletConnect Project ID** - From [Reown.com](https://reown.com) (free)
3. **VeBetterDAO App ID** - Will be guided through registration
4. **Docker Desktop** - For containerization

## The Setup Process

1. 📋 **Environment Configuration** - Fill in your keys
2. 🔨 **Container Building** - Automatic Docker setup  
3. 📜 **Smart Contract Deployment** - Deploy to VeChain testnet
4. 🏆 **VeBetterDAO Registration** - Register for rewards
5. 🚀 **Application Launch** - Start frontend & backend

## Result

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:3001
- **Full VeChain dApp** with wallet integration
- **B3TR token rewards** for learning achievements

## Quick Commands

```bash
./start.sh                    # Start (after initial setup)
docker compose down           # Stop application
docker compose logs -f       # View logs
```
